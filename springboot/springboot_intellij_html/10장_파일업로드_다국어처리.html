3 MultipartFile 인터페이스

컨트롤러에 멀티 파트 요청으로 들어오는 매개변수 중에서 업로드된 파일과 파일 데이터를 표현할 때 사용한다.

MultipartFile 인터페이스의 주요 메서드

메서드설명
getName()멀티 파트 폼 파라미터 이름을 반환
getOriginalFilename()클라이언트의 파일 시스템에서 실제 파일 이름을 반환
isEmpty()업로드한 파일의 존재 여부를 반환
transferTo(File dest)전송된 파일을 지정한 대상 파일로 전송
