1 자바 소개

🎯 학습목표
  • 프로그래밍과 프로그램의 의미를 설명할 수 있다.
  • 자바의 탄생 배경과 4대 특징을 이해한다.
  • 자바의 주요 활용 분야를 예로 들 수 있다.

📖 개념 및 설명

프로그래밍은 컴퓨터에게 일을 시키기 위해 명령을 만드는 과정이고, 그 명령의 모음이 프로그램입니다. 프로그래밍 언어에는 C, C++, Java, Python, JavaScript, C# 등이 있습니다.

자바(Java)는 1991년 제임스 고슬링을 비롯한 썬 마이크로시스템즈 연구원들이 개발했습니다. 가전제품·휴대기기용으로 안정적으로 작동하는 언어가 필요해 만들어졌고, 지금은 오라클(Oracle)이 인수해 관리합니다.

자바 언어의 4대 특징

  • 운영체제에 독립적 — JVM(자바 가상 머신)이 이를 가능하게 함
  • 객체지향 언어 — 유지보수가 쉽고 확장성이 좋음
  • 오픈 소스·풍부한 API — 무료이며 다양한 라이브러리 제공
  • 네트워크·멀티스레드 지원, 안드로이드 앱 개발 언어로도 사용

자바로 개발하는 것

안드로이드 앱안드로이드 폰에서 실행되는 앱
게임마인크래프트 등

2 자바 개발 환경 (JVM·JDK)

🎯 학습목표
  • JVM의 역할과 '바이트 코드' 개념을 설명할 수 있다.
  • JDK, JRE, JVM의 포함 관계를 구분할 수 있다.
  • 컴파일과 빌드의 차이를 설명할 수 있다.

📖 개념 및 설명

JVM(Java Virtual Machine)은 자바 프로그램 실행 환경을 만들어 주는 소프트웨어입니다. 자바 코드를 컴파일한 .class(바이트 코드)는 JVM 위에서 실행됩니다. 덕분에 자바는 하나의 바이트 코드를 어떤 OS에서든 실행할 수 있습니다.

구분설명
JDK (Java Development Kit)자바 개발을 위해 설치하는 라이브러리(개발 도구)
JRE (Java Runtime Environment)자바 프로그램이 실행되는 환경 (JVM 포함)

포함 관계: JDK ⊃ JRE ⊃ JVM — 개발하려면 JDK를, 실행만 하려면 JRE를 설치합니다.

컴파일과 빌드

  • 컴파일(compile): 소스 파일(.java)을 바이트 코드(.class)로 변환. 도구는 javac.exe
  • 빌드(build): 컴파일·링크된 코드를 실행 가능한 형태로 만드는 전체 과정(전처리·컴파일·패키징·배포). 도구로 Maven Gradle
💡 예제

컴파일러(javac)와 실행기(java)의 관계:

HelloJava.java  --(javac 컴파일)-->  HelloJava.class  --(java 실행)-->  JVM에서 실행

4 첫 자바 프로그램 만들기

🎯 학습목표
  • 프로젝트 → 패키지 → 클래스의 계층을 이해하고 생성할 수 있다.
  • main() 메서드의 역할을 설명할 수 있다.
  • 코드를 작성·실행하고 콘솔 결과를 확인할 수 있다.

📖 개념 및 설명

  1. 프로젝트: File → New → Java Project, 이름 Chapter01
  2. 패키지: 프로젝트 우클릭 → New Package → 이름 hello (클래스를 분류하는 폴더)
  3. 클래스: 패키지 우클릭 → New Class → 이름 HelloJava, main() 자동 생성 체크

main() 메서드는 프로그램의 시작점입니다. 실행하려면 반드시 있어야 합니다. 실행 결과는 아래 콘솔(Console)에 출력됩니다.

💡 예제
package hello;

public class HelloJava {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
Hello, Java!

실행: Run → Run As → Java Application. 컴파일된 .class는 프로젝트의 bin 폴더에 생성됩니다.

📖 개념 및 설명

  • 주석: 한 줄 //, 여러 줄 /* ~ */. 실행에 영향을 주지 않는 설명

System 클래스는 java.base > java.lang > System 계층에 있으며, java.lang은 import 없이 사용합니다.

6 변수(Variable)

🎯 학습목표
  • 변수의 개념과 선언·초기화 방법을 설명할 수 있다.
  • 변수 이름 규칙을 지켜 이름을 지을 수 있다.

📖 개념 및 설명

변수는 값을 저장하기 위한 메모리 공간의 이름입니다. 선언은 자료형 이름;, 초기화는 자료형 이름 = 값; 형태입니다.

변수 이름 규칙

  • 알파벳·숫자·_·$로 구성, 대소문자 구분
  • 숫자로 시작 불가, 예약어(int, class, if 등) 사용 불가, 공백 불가
  • 역할이 드러나는 의미 있는 이름을 짓는다
💡 예제
int age = 27;
char grade = 'A';
String fruit = "사과";
System.out.println(fruit + "는 " + age + "살");
사과는 27살

7 자료형(Data Type)

🎯 학습목표

📖 개념 및 설명

자료형은 데이터를 저장하는 공간의 유형입니다. 크게 기본형(문자·숫자·불리언)과 참조형(객체)으로 나뉩니다.

구분자료형크기용도
정수형byte1작은 정수 (-128~127)
short2정수 (-32768~32767)
int4일반 정수 (기본)
long8큰 정수 (뒤에 L)
실수형float4실수 (뒤에 F)
double8정밀한 실수 (기본)
문자형char2문자 1개 (0~65535)
논리형boolean1true / false

char vs String: char는 문자 1개를 홑따옴표('A')로, String은 문자열을 쌍따옴표("abc")로 표기합니다.

💡 예제

long big = 10000000000L;
double pi = 3.14;
boolean pass = true;

8 컴퓨터의 데이터 표현

🎯 학습목표
  • 비트와 2진수의 개념을 설명할 수 있다.
  • ASCII·유니코드로 문자가 저장되는 방식을 이해한다.
  • 2의 보수로 음수를 표현하는 원리를 설명할 수 있다.

📖 개념 및 설명

  • 컴퓨터는 0과 1(비트)로 데이터를 저장한다. 비트는 데이터의 최소 단위.
  • 문자도 숫자로 바꿔 저장한다. 예: 'A' = 65 = 01000001
  • ASCII: 1바이트로 영문·숫자·기호 표현 / 유니코드: 2바이트로 한글 등 전 세계 문자 표현(UTF-8, UTF-16)
  • 2의 보수: 음수 표현 방법. 1의 보수(0↔1 반전) 후 +1. 맨 왼쪽 비트(MSB)가 부호비트
비트 수표현 범위
1 bit0~1 (2개)
2 bit0~3 (4개)
n bit0 ~ 2ⁿ-1
💡 예제

10진수 5를 2의 보수로 -5 만들기:

5      = 00000101
1의 보수 = 11111010   (0↔1 반전)
+1     = 11111011   = -5

9 형 변환(Type Conversion)

🎯 학습목표
  • 묵시적 형변환과 명시적 형변환을 구분할 수 있다.
  • 형변환 시 데이터 손실이 발생하는 경우를 설명할 수 있다.

📖 개념 및 설명

구분방향방법
묵시적(자동)작은 → 큰 자료형자동 변환
명시적(강제)큰 → 작은 자료형(타입) 명시

큰 타입 → 작은 타입 변환 시 소수점이 버려지거나 값이 잘릴 수 있습니다(반올림 아님).

💡 예제
int iNum = 20;
double dNum = iNum;        // 묵시적: 20.0

double d = 3.9;
int i = (int)d;           // 명시적: 3 (소수점 버림)

10 연산자(Operator)

🎯 학습목표
  • 산술·비교·논리·복합대입·삼항 연산자를 사용할 수 있다.
  • 연산자 우선순위를 이해하고 괄호로 제어할 수 있다.

📖 개념 및 설명

종류연산자
산술+ - * /(몫) %(나머지)
증감++ -- (전치/후치)
비교> < >= <= == !=
논리&&(AND) ||(OR) !(NOT)
복합대입+= -= *= /= %=
조건(삼항)조건 ? A : B

우선순위: 단항 → 산술 → 비트이동 → 관계 → 논리 → 조건 → 대입. 헷갈릴 땐 괄호 ()로 명시하는 것이 안전합니다.

💡 예제
int a = 7, b = 3;
System.out.println(a / b);      // 2 (몫)
System.out.println(a % b);      // 1 (나머지)
int max = (a > b) ? a : b;      // 7 (삼항)

  • final 상수를 선언하고 사용할 수 있다.

📖 개념 및 설명

  • Scanner: 표준 입력(키보드)에서 값을 읽는 클래스. import java.util.Scanner; 필요, 사용 후 close()
  • 메서드: nextInt(), nextDouble(), next(), nextLine()
  • 상수(final): 변하지 않는 값. 이름은 대문자 관례. 재대입하면 컴파일 오류
💡 예제
import java.util.Scanner;

final double PI = 3.14;
Scanner sc = new Scanner(System.in);
System.out.print("반지름 입력: ");
int r = sc.nextInt();
System.out.println("넓이: " + (r * r * PI));
sc.close();

실습 11-1. 몫과 나머지 (Bread.java)

빵 25개를 4명이 나눠 가질 때 각자의 몫과 남은 개수를 구해 출력하세요.

int bread = 25, people = 4;

System.out.println("나머지: " + (bread % people)); // 1

실습 11-2. 홀짝 판별 (EvenOdd.java)

정답 보기 
Scanner sc = new Scanner(System.in);
