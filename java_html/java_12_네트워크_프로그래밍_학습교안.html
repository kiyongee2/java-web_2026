1 네트워크와 서버·클라이언트

🎯 학습목표
  • 서버와 클라이언트의 역할을 구분할 수 있다.
  • LAN·MAN·WAN을 구분할 수 있다.

📖 개념 및 설명

  • 서버(Server): 서비스를 제공하는 쪽. 연결을 수락하고 요청을 처리해 응답
  • 클라이언트(Client): 서비스를 받는 쪽. 웹브라우저·메신저 등
  • 범위별: LAN(가까운 영역) → MAN(도시·건물) → WAN(인터넷)
✏️ 실습문제

2 IP 주소와 포트

🎯 학습목표
  • IP 주소와 포트의 역할을 구분할 수 있다.

📖 개념 및 설명

  • IP 주소: 컴퓨터의 고유 주소(IPv4는 0~255 네 마디). 확인: ipconfig
  • 포트(Port): 한 컴퓨터 안에서 프로그램을 구분하는 번호(0~65535). 예: 웹 80, MySQL 3306
💡 예제
InetAddress ia = InetAddress.getLocalHost();
System.out.println(ia.getHostAddress());   // 내 IP

3 TCP와 소켓

🎯 학습목표
  • TCP의 특징을 설명할 수 있다.
  • ServerSocket과 Socket의 역할을 구분할 수 있다.

📖 개념 및 설명

TCP는 연결 지향적 프로토콜로, 데이터를 정확하고 순차적으로 전달합니다. 자바에서는 서버가 ServerSocket으로 연결을 기다리고, 클라이언트가 Socket으로 연결을 요청합니다.

정답 보기

서버: ServerSocket / 클라이언트: Socket

4 서버 프로그램 (ServerSocket)

🎯 학습목표
  • ServerSocket을 생성하고 연결을 수락할 수 있다.

📖 개념 및 설명

서버는 포트에 바인딩한 ServerSocket을 만들고, accept()로 클라이언트 연결을 기다립니다. accept()는 연결이 오면 통신용 Socket을 반환합니다.

💡 예제
ServerSocket server = new ServerSocket(50001);
Socket socket = server.accept();   // 연결 수락(대기)
✏️ 실습문제

실습 12-4. accept()

accept() 메서드는 무엇을 할 때까지 대기하며, 무엇을 반환하나요?

정답 보기

5 클라이언트 (Socket)

🎯 학습목표
  • Socket으로 서버에 연결을 요청할 수 있다.

📖 개념 및 설명

클라이언트는 Socket을 만들 때 서버의 IP와 포트를 지정해 연결을 요청합니다. 통신이 끝나면 close()로 닫습니다.

💡 예제
Socket socket = new Socket("localhost", 50001);
// ... 통신 ...
socket.close();

6 데이터 주고받기

🎯 학습목표
  • 소켓의 입출력 스트림으로 데이터를 주고받을 수 있다.

📖 개념 및 설명

소켓에서 getOutputStream()으로 데이터를 보내고, getInputStream()으로 받습니다. 문자열은 getBytes()로 바이트 배열로 변환해 전송하며, 인코딩(UTF-8)을 맞춰야 한글이 깨지지 않습니다.

💡 예제
// 보내기
byte[] bytes = "안녕".getBytes("UTF-8");
OutputStream os = socket.getOutputStream();
os.write(bytes);
os.flush();

// 받기
byte[] buf = new byte[100];
int n = socket.getInputStream().read(buf);
String msg = new String(buf, 0, n, "UTF-8");
