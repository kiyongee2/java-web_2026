1 입출력 스트림 개념

🎯 학습목표
  • 스트림의 의미와 입력·출력 방향을 이해한다.
  • 바이트 스트림과 문자 스트림을 구분할 수 있다.

📖 개념 및 설명

스트림은 데이터가 물 흐르듯 이동하는 통로입니다. 읽어들이면 입력 스트림, 내보내면 출력 스트림입니다.

구분바이트 기반문자 기반
입력InputStreamReader
출력OutputStreamWriter

그림·동영상 등은 바이트 스트림, 텍스트는 문자 스트림이 적합합니다.

2 문자 스트림 (Writer / Reader)

🎯 학습목표
  • FileWriter로 텍스트를 파일에 쓸 수 있다.
  • FileReader로 텍스트를 읽을 수 있다.

📖 개념 및 설명

파일 입출력의 기본 과정은 ① 열기(open) → ② 읽기/쓰기 → ③ 닫기(close)입니다. 다 쓴 스트림은 반드시 close()로 닫아 자원을 반납합니다.

💡 예제
FileWriter fw = new FileWriter("memo.txt");
fw.write("안녕하세요");
fw.close();

FileReader fr = new FileReader("memo.txt");
int c;
while ((c = fr.read()) != -1)
    System.out.print((char)c);
fr.close();
안녕하세요

3 바이트 스트림

🎯 학습목표
  • FileInputStream·FileOutputStream으로 바이트 데이터를 다룰 수 있다.

📖 개념 및 설명

이미지·동영상 등 이진 파일은 바이트 스트림으로 처리합니다. read()는 1바이트를 읽고, 파일 끝(EOF)에서는 -1을 반환합니다.

💡 예제
FileOutputStream out = new FileOutputStream("data.bin");
out.write(65);   // 'A' 저장
out.close();
✏️ 실습문제

실습 10-3. EOF 판단

read()가 어떤 값을 반환하면 파일의 끝에 도달한 것인가요?

정답 보기

-1을 반환하면 파일의 끝(EOF)이다.

4 File 클래스 · 파일 복사

🎯 학습목표
  • File 클래스로 파일 정보를 다룰 수 있다.
  • 입력·출력 스트림을 조합해 파일을 복사할 수 있다.

📖 개념 및 설명

File 클래스는 파일·디렉토리 생성, 존재 확인, 삭제 등 파일 시스템 작업을 담당합니다. 파일 복사는 입력 스트림에서 읽어 출력 스트림으로 쓰는 방식으로 구현합니다.

💡 예제
FileInputStream in = new FileInputStream("src.jpg");
FileOutputStream out = new FileOutputStream("copy.jpg");
int b;
while ((b = in.read()) != -1) out.write(b);
in.close(); out.close();

5 보조 스트림 (Buffered)

🎯 학습목표
  • 보조 스트림의 역할을 이해한다.
  • BufferedReader의 readLine()으로 줄 단위 읽기를 할 수 있다.

📖 개념 및 설명

보조 스트림은 기반 스트림에 연결해 편의 기능을 더합니다. Buffered 스트림은 내부 버퍼로 속도를 높이고, BufferedReader.readLine()은 한 줄씩 읽어 편리합니다. InputStreamReader는 바이트를 문자로 변환합니다.

💡 예제
BufferedReader br = new BufferedReader(
    new FileReader("memo.txt"));
String line;
while ((line = br.readLine()) != null)
    System.out.println(line);
br.close();
✏️ 실습문제

실습 10-5. 줄 단위 읽기

키보드 입력을 한 줄 읽는 BufferedReader 코드를 작성하세요. (System.in 활용)

정답 보기 
BufferedReader br = new BufferedReader(
    new InputStreamReader(System.in));
String line = br.readLine();

6 DataStream

🎯 학습목표
  • DataStream으로 자료형을 보존하며 읽고 쓸 수 있다.

📖 개념 및 설명

DataInputStream/DataOutputStream은 메모리의 0·1 상태를 그대로 읽고 써서 자료형의 크기가 보존됩니다. writeInt(), writeDouble(), writeUTF() 등으로 타입별로 저장합니다.

💡 예제
DataOutputStream dos = new DataOutputStream(
    new FileOutputStream("score.dat"));
dos.writeInt(100);
dos.writeUTF("홍길동");
dos.close();
✏️ 실습문제

실습 10-6. 타입 보존

일반 문자 스트림 대신 DataStream을 쓰면 어떤 이점이 있나요?

정답 보기

int·double 등 자료형의 크기가 그대로 보존되어, 저장한 타입 그대로 다시 읽을 수 있다.
