1 람다식(lambda)

🎯 학습목표
  • 람다식의 개념과 장점을 설명할 수 있다.
  • 메서드를 람다식으로 간결하게 표현할 수 있다.

📖 개념 및 설명

람다식은 자바 8부터 지원하는 이름 없는 익명 함수입니다. 객체를 만들지 않고 인터페이스 구현만으로 메서드를 표현합니다. 형식은 (매개변수) -> { 실행문 }이며, 코드가 간결해집니다.

  • 매개변수가 하나면 괄호 생략 가능: x -> ...
  • 실행문이 한 줄이면 중괄호·return 생략 가능: (x, y) -> x + y
💡 예제
// 일반 메서드
int add(int x, int y) { return x + y; }

// 람다식
(x, y) -> x + y
✏️ 실습문제

2 함수형 인터페이스

🎯 학습목표
  • 함수형 인터페이스의 조건을 이해한다.
  • 람다식을 함수형 인터페이스에 대입해 호출할 수 있다.

📖 개념 및 설명

람다식을 담으려면 추상 메서드가 딱 하나인 함수형 인터페이스가 필요합니다. @FunctionalInterface를 붙이면 조건 위반을 컴파일러가 잡아줍니다.

💡 예제
@FunctionalInterface
interface Calc { int calc(int x, int y); }

Calc add = (x, y) -> x + y;
System.out.println(add.calc(3, 4));   // 7
✏️ 실습문제

실습 9-2. 함수형 인터페이스 사용

Calc 타입 변수에 뺄셈 람다식을 대입해 10 - 3을 계산·출력하세요.

정답 보기 
Calc sub = (x, y) -> x - y;
System.out.println(sub.calc(10, 3));   // 7

3 스트림(Stream)

🎯 학습목표
  • 스트림의 개념을 이해한다.
  • 배열·컬렉션에서 스트림을 얻어 처리할 수 있다.

📖 개념 및 설명

스트림은 배열이나 컬렉션의 데이터를 람다식으로 처리하는 반복자입니다. 반복문 없이 데이터를 거르고·변환하고·모으는 작업을 선언적으로 표현할 수 있습니다.

💡 예제
List<String> list = List.of("사과", "바나나", "포도");
list.stream().forEach(System.out::println);
✏️ 실습문제

정답 보기 
List.of(1, 2, 3).stream()
    .forEach(System.out::println);

4 스트림 연산 (filter · map)

🎯 학습목표
  • 중간 연산(filter, map)과 최종 연산(forEach, count, sum)을 구분할 수 있다.

📖 개념 및 설명

  • 중간 연산: 데이터를 거르거나 변환 — filter(), map(), sorted()
  • 최종 연산: 결과를 소모·집계 — forEach(), count(), sum()
💡 예제
// 길이가 3 이상인 문자열만 출력
list.stream()
    .filter(s -> s.length() >= 3)
    .forEach(System.out::println);
✏️ 실습문제

실습 9-4. 짝수만 합산

스트림으로 [1,2,3,4,5,6]에서 짝수만 골라 합을 구하세요. (filter + mapToInt + sum)

정답 보기 
int sum = List.of(1,2,3,4,5,6).stream()
    .filter(n -> n % 2 == 0)
    .mapToInt(Integer::intValue)
    .sum();   // 12

6 Thread 생성과 실행

🎯 학습목표
  • Runnable을 구현해 작업 스레드를 만들 수 있다.
  • start()로 스레드를 실행할 수 있다.

📖 개념 및 설명

작업 스레드는 Runnable 인터페이스의 run()을 구현해 만듭니다. Thread 객체에 넘긴 뒤 start()를 호출하면 새 스레드로 실행됩니다. 람다식으로도 간결하게 작성할 수 있습니다.

💡 예제
// 람다식으로 스레드 실행
Thread t = new Thread(() -> {
    for (int i = 0; i < 3; i++)
        System.out.println("작업 " + i);
});
t.start();
✏️ 실습문제

실습 9-6. 스레드 실행

"안녕하세요"를 출력하는 작업을 별도 스레드로 실행하는 코드를 람다식으로 작성하세요.

정답 보기 
new Thread(() -> System.out.println("안녕하세요")).start();
