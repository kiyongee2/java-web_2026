1 상속(Inheritance)

🎯 학습목표
  • 상속의 개념과 상위·하위 클래스를 구분할 수 있다.
  • extends로 클래스를 확장할 수 있다.

📖 개념 및 설명

  • 클래스를 정의할 때 이미 구현된 클래스를 상속(inheritance) 받아 속성이나 기능(메서드)이 확장되는 클래스를 구현할 수 있다.
  • 상속하는 클래스 : 상위 클래스(parent class)
  • 상속받는 클래스 : 하위 클래스(child class)
class B extends A {   // B가 A를 상속받는다 (A: 상위, B: 하위)
    .....
}

간단한 예 — Animal을 상속한 Dog는 부모의 eat()를 그대로 물려받고 자신의 bark()를 추가한다.

class Animal {
    public void eat() {
        System.out.println("먹습니다.");
    }
}

// Animal을 상속한 Dog
class Dog extends Animal {
    public void bark() {   // Dog가 추가한 기능
        System.out.println("멍멍!");
    }
}

public class Test {
    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.eat();    // Animal에서 상속받은 기능 → 먹습니다.
        dog.bark();   // Dog가 추가한 기능 → 멍멍!
    }
}

2 super() – 부모 멤버 호출

🎯 학습목표
  • super()로 부모 생성자를 호출할 수 있다.
  • super.멤버로 부모의 멤버에 접근할 수 있다.

📖 개념 및 설명

자식 생성자에서 super(...)를 쓰면 부모 생성자를 먼저 호출합니다. 부모의 메서드나 변수를 명시적으로 쓸 때는 super.메서드()를 사용합니다.

📖 정보 은닉(Information Hiding)

  • 접근 제어자 : 접근 권한 지정
    • public : 외부 클래스에서 접근 가능
    • private : 클래스의 외부에서 클래스 내부의 멤버 변수나 메서드에 접근 못하게 하는 경우 사용
  • 변수에 대해서는 필요한 경우 get(), set() 메서드를 제공한다.
접근 제어자설명
public외부 클래스 어디에서나 접근할 수 있다.
private같은 클래스 내부만 가능, 그 외 접근 불가
protected같은 패키지 내부와 상속 관계의 클래스에서만 접근(다른 패키지에서도 가능)

예 — 차량(Car)과 이를 상속한 전기차(EV). EV 생성자에서 super(brand, model)로 부모를 초기화하고, showInfo()에서 super.showInfo()로 부모 메서드를 호출한다.

💡 Car 예제 — ① Car (상위 클래스)
package inheritance.car;

public class Car {
    protected String brand;   // 브랜드명
    protected String model;   // 모델명
    protected int speed;      // 속도

    public Car(String brand, String model) {
        this.brand = brand;
        this.model = model;
        this.speed = 0;
    }

    public void accelerate(int amount) {   // 가속 메서드
        speed += amount;
        System.out.println(model + " 가속 - 현재 속도: " + speed + "km/h");
    }

    public void brake(int amount) {   // 감속 메서드
        speed -= amount;
        if (speed < 0) speed = 0;
        System.out.println(model + " 감속 - 현재 속도: " + speed + "km/h");
    }

    public void showInfo() {
        System.out.println("== 자동차 정보 ==");
        System.out.println("제조사: " + brand);
        System.out.println("모델명: " + model);
    }
}
💡 Car 예제 — ② EV (하위 클래스, super() 사용)
public class EV extends Car {
    private int battery;   // 배터리 잔량(0~100%)

    public EV(String brand, String model, int battery) {
        super(brand, model);   // Car의 멤버 변수 상속(부모 생성자 호출)
        this.battery = battery;
    }

    public void charge(int amount) {
        battery += amount;
        if (battery > 100) battery = 100;
        System.out.println(model + " 충전됨 - 배터리: " + battery + "%");
    }

    @Override   // 메서드 재정의
    public void showInfo() {
        super.showInfo();   // Car의 showInfo() 상속(호출)
        System.out.println("배터리 잔량: " + battery + "%");
    }
}
💡 Car 예제 — ③ CarTest (실행)

실습 5-2. super 사용 (Person / Student)

부모 Person(이름 name)과 이를 상속한 Student(학교 school)가 있습니다. Student 생성자에서 super()로 부모의 name을 초기화하고, introduce()를 재정의해 부모 소개에 학교 정보를 덧붙이세요.

정답 보기 
class Person {
    protected String name;
    public Person(String name) { this.name = name; }
    public void introduce() {
        System.out.println("안녕하세요, " + name + "입니다.");
    }
}

class Student extends Person {
    private String school;
    public Student(String name, String school) {
        super(name);        // 부모(Person) 생성자 호출 → name 초기화
        this.school = school;
    }
    @Override
    public void introduce() {
        super.introduce();   // 부모의 introduce() 호출
        System.out.println(school + " 학생입니다.");
    }
}

public class Test {
    public static void main(String[] args) {
        Student stu = new Student("홍길동", "한국대");
        stu.introduce();
    }
}

3 메서드 재정의(Overriding)

🎯 학습목표
  • 오버라이딩의 개념과 필요성을 설명할 수 있다.
  • @Override로 부모 메서드를 재정의할 수 있다.

📖 개념 및 설명

상속받은 메서드가 자식에 맞지 않을 때, 같은 이름·형태로 다시 구현하는 것이 오버라이딩입니다. @Override 애너테이션을 붙이면 실수를 컴파일러가 잡아줍니다.

💡 예제
class EV extends Car {
    @Override
    void accelerate() {
        System.out.println("조용히 가속");   // 재정의
    }
}

매출전표(SaleStatement) 예제 — 오버라이딩(printData 재정의) 활용. Drink(음료) 클래스를 만들고, 이를 상속한 Alcohol(주류) 클래스를 만든다.

💡 예제 — ① Drink (상위 클래스)
package inheritance.salestatement;

public class Drink {
    protected String name;      // 상품명
    protected int price;         // 가격
    protected int quantity;      // 수량

    public Drink(String name, int price, int quantity) {
        this.name = name;
        this.price = price;
        this.quantity = quantity;
    }

    public int calcPrice() {
        return price * quantity;   // 금액 = 가격 * 수량
    }

    public static void printTitle() {   // 제목 출력
        System.out.println("상품명\t가격\t수량\t금액");
    }

    public void printData() {         // 데이터 출력
        System.out.println(name + "\t" + price + "\t" +
                           quantity + "\t" + calcPrice());
    }
}
💡 예제 — ② Alcohol (하위 클래스, super() · 재정의)
public class Alcohol extends Drink {
    private float alcper;   // 알콜 도수

    public Alcohol(String name, int price, int quantity, float alcper) {
        super(name, price, quantity);   // Drink 생성자 호출
        this.alcper = alcper;
    }

    public static void printTitle() {
        System.out.println("상품명(도수[%])\t가격\t수량\t금액");
    }

    @Override
    public void printData() {   // 메서드 재정의
        System.out.println(name + "(" + alcper + ")\t" + price +
                           "\t" + quantity + "\t" + calcPrice());
    }
}
💡 예제 — ③ SaleStatement (실행)
package inheritance.salestatement;

public class SaleStatement {
    public static void main(String[] args) {
        Drink coffee = new Drink("커피", 2500, 4);
        Drink tea = new Drink("녹차", 3500, 3);
        Alcohol soju = new Alcohol("소주", 4000, 2, 15.2f);
        Alcohol beer = new Alcohol("맥주", 3000, 3, 5.5f);

        Drink.printTitle();   // 클래스 이름으로 직접 접근(static)
        coffee.printData();
        tea.printData();
        System.out.println();

        Alcohol.printTitle();
        soju.printData();
        beer.printData();

        // 총금액 계산하기
        int total = 0;
        total = coffee.calcPrice() + tea.calcPrice() + soju.calcPrice();
        System.out.println("***** 합계 금액 : " + total + "원 *****");
    }
}

Alcohol은 Drink의 name·price·quantity와 calcPrice()를 상속받아 super()로 초기화하고, printData()를 재정의(도수 표시)한다. static 메서드 printTitle()은 클래스 이름으로 호출한다.

4 다형성(Polymorphism)

🎯 학습목표
  • 다형성의 개념과 장점을 설명할 수 있다.
  • 부모 타입 변수로 자식 객체를 다룰 수 있다.

📖 개념 및 설명

  • 다형성(polymorphism)이란 하나의 타입(자료형)에 대입되는 객체에 따라서 실행 결과가 다양한 형태로 나오는 성질을 말한다.
  • 동적 바인딩 — 메서드가 인스턴스의 타입에 맞게 실행되는 것을 말한다.
  • 장점 : 코드의 재사용성 향상, 유지보수 용이
💡 예제 — ① Animal · Human · Horse · Eagle
package polymorphism.animal;

class Animal {
    public void move() {
        System.out.println("동물이 움직입니다.");
    }
}

class Human extends Animal {
    public void move() {
        System.out.println("사람이 두 발로 걷습니다.");
    }
}

class Horse extends Animal {
    public void move() {
        System.out.println("말이 네 발로 뜁니다.");
    }
}

class Eagle extends Animal {
    public void move() {
        System.out.println("독수리가 하늘을 납니다.");
    }
}
💡 예제 — ② AnimalTest (배열 + 동적 바인딩)
public class AnimalTest {
    public static void main(String[] args) {
        // 다형성 -> 부모 타입 = 자식 타입
        // Animal human = new Human();
        // human.move();  // 메서드 - 동적 바인딩

        // 배열로 관리
        Animal[] animals = {
            new Human(),
            new Horse(),
            new Eagle()
        };

        for (Animal animal : animals)
            animal.move();   // 실제 객체 타입에 맞게 실행(동적 바인딩)
    }
}
사람이 두 발로 걷습니다.
말이 네 발로 뜁니다.
독수리가 하늘을 납니다.

부모 타입 Animal 배열 하나로 자식 객체들을 담고, animal.move() 하나의 호출이 각 객체에 맞는 메서드로 실행된다. 이것이 다형성 + 동적 바인딩이다.

5 자동 타입 변환(업캐스팅)

🎯 학습목표
  • 하위→상위 타입 변환이 자동으로 일어남을 이해한다.

📖 개념 및 설명

상속 관계에서 자식 타입 → 부모 타입 변환은 자동으로 이루어집니다(업캐스팅). 부모 타입 변수는 부모가 정의한 멤버만 사용할 수 있습니다.

💡 예제
Animal a = new Cat();   // 자동 타입 변환(업캐스팅)

📖 매개변수의 다형성

매개값을 다양화하기 위해 매개변수를 부모 타입으로 선언하고, 호출할 때 자식 객체를 대입한다. 하나의 메서드로 여러 자식 객체를 처리할 수 있다.

💡 예제 — 매개변수의 다형성
public class AnimalTest {
    // 매개변수를 부모 타입(Animal)으로 선언
    public static void moveAnimal(Animal animal) {
        animal.move();   // 대입된 자식 객체의 move() 실행
    }

    public static void main(String[] args) {
        moveAnimal(new Human());   // 호출할 때 자식 객체를 대입
        moveAnimal(new Horse());
        moveAnimal(new Eagle());
    }
}
사람이 두 발로 걷습니다.
말이 네 발로 뜁니다.
독수리가 하늘을 납니다.

같은 moveAnimal(Animal) 메서드에 서로 다른 자식 객체(Human·Horse·Eagle)를 넘겨도, 실제 대입된 객체에 맞는 move()가 실행된다. 이것이 매개변수의 다형성이다.

✏️ 실습문제

실습 5-3. 매개변수의 다형성 (Shape)

도형 Shape(draw())를 상속한 Circle·Rectangle이 있습니다. 매개변수를 부모 타입 Shape로 받는 printArea(Shape s) 메서드를 만들어, 서로 다른 도형을 넘겨도 각자의 draw()가 실행되도록 하세요.

정답 보기 
class Shape {
    public void draw() { System.out.println("도형을 그립니다."); }
}

class Circle extends Shape {
    @Override public void draw() { System.out.println("● 원을 그립니다."); }
}

class Rectangle extends Shape {
    @Override public void draw() { System.out.println("■ 사각형을 그립니다."); }
}

public class Test {
    // 매개변수를 부모 타입(Shape)으로 선언
    public static void printArea(Shape s) {
        s.draw();   // 대입된 자식 도형에 맞게 실행
    }

    public static void main(String[] args) {
        printArea(new Circle());      // → ● 원을 그립니다.
        printArea(new Rectangle());   // → ■ 사각형을 그립니다.
    }
}
● 원을 그립니다.
■ 사각형을 그립니다.

같은 printArea(Shape) 메서드에 Circle·Rectangle을 넘겨도 각 객체의 draw()가 실행된다. 새 도형(Triangle 등)을 추가해도 이 메서드는 고칠 필요가 없다.

6 강제 타입 변환 · instanceof

🎯 학습목표
  • 다운캐스팅이 필요한 상황을 이해한다.
  • instanceof로 타입을 확인한 후 안전하게 변환할 수 있다.

📖 개념 및 설명

부모 타입으로 올렸던 객체를 자식 타입으로 되돌리는 것이 다운캐스팅입니다((자식) 명시). 자식만의 메서드를 써야 할 때 필요하며, instanceof로 실제 타입을 확인한 뒤 변환해야 안전합니다.

먼저 기본 자료형의 타입 변환을 보자. 작은 자료형 → 큰 자료형은 자동, 큰 자료형 → 작은 자료형은 (타입)으로 강제 변환한다.

public class TypeConversion {
    public static void main(String[] args) {
        // 기본 자료형의 타입 변환 예제
        int iNum = 10;
        float fNum = iNum;      // 자동타입 변환(작은 자료형 → 큰 자료형)

        System.out.println(iNum + ", " + fNum);

        double dNum = 2.54;
        iNum = (int)dNum;         // 강제타입 변환(큰 자료형 → 작은 자료형)

        System.out.println(iNum);   // 2 (소수점 버림)
    }
}

💡 예제 — ① 자식만의 메서드를 가진 클래스들

부모 타입 배열에 담으면 자식 고유 메서드(readBook·run·hunting)에는 접근할 수 없다. 이때 다운캐스팅이 필요하다.

class Animal {
    public void move() { System.out.println("동물이 움직입니다."); }
}

class Human extends Animal {
    @Override public void move() { System.out.println("사람이 두 발로 걷습니다."); }
    public void readBook() { System.out.println("사람이 책을 읽습니다."); }
}

class Horse extends Animal {
    @Override public void move() { System.out.println("말이 네 발로 뜁니다."); }
    public void run() { System.out.println("말이 사람을 태우고 빠르게 달립니다."); }
}

class Eagle extends Animal {
    @Override public void move() { System.out.println("독수리가 하늘을 납니다."); }
    public void hunting() { System.out.println("독수리가 물고기를 사냥합니다."); }
}
💡 예제 — ② AnimalTest (instanceof 다운캐스팅)
public class AnimalTest {
    static Animal[] animals = new Animal[3];   // 객체를 저장할 배열

    public static void main(String[] args) {
        // 객체를 생성하여 저장(다형성)
        animals[0] = new Human();
        animals[1] = new Horse();
        animals[2] = new Eagle();

        // 부모 타입이라 move()만 호출 가능 (readBook() 등은 불가)
        for (Animal a : animals) a.move();

        System.out.println("=== 원래 형으로 다운캐스팅 ===");
        downCasting();
    }

    // 다운 캐스팅 - instanceof로 실제 타입 확인 후 형변환
    public static void downCasting() {
        for (int i = 0; i < animals.length; i++) {
            Animal animal = animals[i];
            if (animal instanceof Human) {
                Human human = (Human)animal;   // 다운캐스팅
                human.readBook();
            } else if (animal instanceof Horse) {
                Horse horse = (Horse)animal;
                horse.run();
            } else if (animal instanceof Eagle) {
                Eagle eagle = (Eagle)animal;
                eagle.hunting();
            } else {
                System.out.println("지원하지 않는 타입입니다.");
            }
        }
    }
}
사람이 두 발로 걷습니다.
말이 네 발로 뜁니다.
독수리가 하늘을 납니다.
=== 원래 형으로 다운캐스팅 ===
사람이 책을 읽습니다.
말이 사람을 태우고 빠르게 달립니다.
독수리가 물고기를 사냥합니다.

instanceof로 실제 타입을 확인한 뒤 (자식)으로 다운캐스팅하면, 자식만의 메서드(readBook·run·hunting)를 안전하게 호출할 수 있다.

✏️ 실습문제

실습 5-4. 안전한 다운캐스팅

Animal a가 실제로 Dog일 때만 bark()를 호출하도록 코드를 작성하세요.

정답 보기 
public static void callBark(Animal a) {
    // instanceof로 실제 타입을 확인한 뒤 다운캐스팅
    if (a instanceof Dog) {
        Dog dog = (Dog)a;   // 안전한 다운캐스팅
        dog.bark();
    } else {
        System.out.println("Dog가 아니라 bark()를 호출할 수 없습니다.");
    }
}

instanceof 확인 없이 (Dog)a로 바로 캐스팅하면, 실제 객체가 Dog가 아닐 때 ClassCastException이 발생한다. 그래서 확인 후 변환하는 것이 안전하다.

참고 — 업캐스팅 후 자식 메서드를 쓰려면 instanceof 확인 후 다운캐스팅한다.

Car c = new EV();   // 업캐스팅 (자동)
c.accelerate(10);   // OK - Car에 정의된 메서드
// c.charge(20);      // 오류! EV(자식)에만 있는 메서드는 사용 불가

// 자식 메서드를 쓰려면 다운캐스팅 필요
if (c instanceof EV) {
    EV ev = (EV)c;
    ev.charge(20);   // OK
}
