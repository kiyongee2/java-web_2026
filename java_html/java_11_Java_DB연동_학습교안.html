1 JDBC와 DB 연결

🎯 학습목표
  • JDBC의 역할을 설명할 수 있다.
  • MySQL 설치와 계정·DB 구성 흐름을 이해한다.

📖 개념 및 설명

JDBC(Java Database Connectivity)는 자바 애플리케이션을 DBMS에 연결해 주는 API입니다. 각 DBMS 제조사(오라클·MySQL 등)가 드라이버를 제공합니다. MySQL 설치 후 계정(예: javauser)과 데이터베이스(예: javadb)를 만들어 사용합니다.

2 SQL 기초 (DDL · DML · DCL)

🎯 학습목표
  • SQL의 세 갈래(DDL·DML·DCL)를 구분할 수 있다.
  • 기본 CRUD SQL문을 작성할 수 있다.

📖 개념 및 설명

구분역할명령어
DDL (정의어)테이블 구조 생성·변경·삭제CREATE, ALTER, DROP
DML (조작어)데이터 저장·조회·수정·삭제INSERT, SELECT, UPDATE, DELETE
DCL (제어어)권한 관리GRANT, REVOKE
💡 예제
INSERT INTO users(user_id, name) VALUES ('hong', '홍길동');
SELECT * FROM users WHERE id = 1;
UPDATE users SET name = '김철수' WHERE id = 1;
DELETE FROM users WHERE id = 1;

4 DTO와 DAO

🎯 학습목표

📖 개념 및 설명

  • DTO(Data Transfer Object): 데이터를 담아 전달하는 객체. 테이블 필드를 속성으로, getter/setter만 가짐(로직 없음)

💡 예제
public class Users {   // DTO
    private Integer id;
    private String userId, password, name;
    // getter / setter ...
}

5 PreparedStatement

🎯 학습목표
  • executeUpdate()와 executeQuery()를 구분해 쓸 수 있다.
  • ? 파라미터로 안전하게 값을 바인딩할 수 있다.

📖 개념 및 설명

PreparedStatement는 ? 자리에 값을 채워 SQL을 실행합니다. INSERT·UPDATE·DELETE는 executeUpdate(), SELECT는 executeQuery()로 ResultSet을 받습니다. SQL 인젝션 방지에도 유리합니다.

💡 예제
String sql = "INSERT INTO users(user_id, name) VALUES(?, ?)";
PreparedStatement pstmt = conn.prepareStatement(sql);
pstmt.setString(1, "hong");
pstmt.setString(2, "홍길동");
pstmt.executeUpdate();
