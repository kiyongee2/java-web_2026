1 Object 클래스

🎯 학습목표
  • Object가 모든 클래스의 최상위 클래스임을 이해한다.
  • toString()·equals()를 재정의할 수 있다.

📖 개념 및 설명

모든 클래스는 자동으로 Object를 상속받습니다. 주요 메서드로 toString()(객체를 문자열로), equals()(두 객체가 같은지), hashCode()(해시 값)가 있으며, 필요에 따라 재정의합니다.

💡 예제
@Override
public String toString() {
    return "Book[" + title + "]";
}
✏️ 실습문제

실습 7-1. equals 재정의

Book 클래스에서 bookNumber가 같으면 같은 책으로 보도록 equals()를 재정의하는 뼈대를 쓰세요.

정답 보기 
@Override
public boolean equals(Object obj) {
    if (obj instanceof Book) {
        Book b = (Book)obj;
        return this.bookNumber == b.bookNumber;
    }
    return false;
}

2 String 주요 메서드

🎯 학습목표
  • 문자열을 검색·추출·변환하는 메서드를 사용할 수 있다.

📖 개념 및 설명

메서드기능
charAt(i)i번째 문자 반환
indexOf(문자열)위치 반환(없으면 -1)
substring(a, b)a부터 b-1까지 추출
replace(전, 후)문자열 치환
split(구분자)배열로 분리
toUpperCase()대문자 변환
💡 예제
String s = "Hello,Java";
System.out.println(s.substring(0, 5));   // Hello
String[] arr = s.split(",");      // [Hello, Java]
✏️ 실습문제

실습 7-2. 문자열 분리

"사과,바나나,포도"를 쉼표로 분리해 각 과일을 한 줄씩 출력하세요.

정답 보기 
String[] fruits = "사과,바나나,포도".split(",");
for (String f : fruits) System.out.println(f);

3 Wrapper 클래스

🎯 학습목표
  • 기본형과 Wrapper 클래스의 관계를 이해한다.
  • 문자열을 숫자로 변환할 수 있다.

📖 개념 및 설명

기본 자료형을 객체로 다뤄야 할 때 Wrapper 클래스를 씁니다. int→Integer, double→Double 등. 문자열↔숫자 변환에도 자주 사용합니다.

💡 예제
int n = Integer.parseInt("123");    // 문자열 → int
String s = Integer.toString(456);  // int → 문자열
✏️ 실습문제

실습 7-3. 문자열을 숫자로

"50"과 "30"을 정수로 변환해 합을 출력하세요.

정답 보기 
int a = Integer.parseInt("50");
int b = Integer.parseInt("30");
System.out.println(a + b);   // 80

4 예외(Exception)의 이해

🎯 학습목표
  • 예외의 개념과 일반 예외·실행 예외를 구분할 수 있다.

📖 개념 및 설명

예외는 잘못된 조작이나 코딩으로 발생하는 오류입니다. 예외 처리를 하면 프로그램이 비정상 종료되지 않습니다.

종류설명
일반 예외처리 안 하면 컴파일 불가(컴파일 체크)
실행 예외(RuntimeException)처리 생략해도 컴파일됨

예: ArrayIndexOutOfBoundsException, NumberFormatException, InputMismatchException

✏️ 실습문제

배열의 없는 인덱스에 접근할 때 발생하는 예외 이름은 무엇인가요?

정답 보기

ArrayIndexOutOfBoundsException (실행 예외)

5 try ~ catch ~ finally

🎯 학습목표
  • try-catch로 예외를 처리할 수 있다.
  • finally 블록의 역할을 이해한다.

📖 개념 및 설명

try 블록에서 예외가 나면 catch가 처리하고, finally는 예외 발생 여부와 상관없이 항상 실행됩니다(자원 정리에 사용).

💡 예제
try {
    int r = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("0으로 나눌 수 없음");
} finally {
    System.out.println("처리 완료");
}
0으로 나눌 수 없음
처리 완료
✏️ 실습문제

실습 7-5. 입력 예외 처리

숫자를 입력받을 때 문자가 들어오면 "숫자를 입력하세요"를 출력하도록 try-catch로 작성하세요.

정답 보기 
try {
    int n = sc.nextInt();
} catch (InputMismatchException e) {
    System.out.println("숫자를 입력하세요");
}

6 throw · throws

🎯 학습목표
  • throw로 예외를 직접 발생시킬 수 있다.
  • throws로 예외 처리를 호출자에게 미룰 수 있다.

📖 개념 및 설명

  • throw: 예외 객체를 직접 만들어 던짐 — throw new 예외("메시지")
  • throws: 메서드가 예외를 처리하지 않고 호출한 곳으로 넘김
💡 예제
void setAge(int age) {
    if (age < 0)
        throw new IllegalArgumentException("나이는 음수 불가");
}
✏️ 실습문제

실습 7-6. 예외 발생시키기

잔액보다 큰 금액을 출금하려 하면 예외를 발생시키는 코드를 throw로 작성하세요.

정답 보기 
if (amount > balance)
    throw new IllegalArgumentException("잔액 부족");
