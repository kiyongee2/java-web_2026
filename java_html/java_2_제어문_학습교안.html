1 조건문 if · if-else

🎯 학습목표
  • 조건문의 개념과 필요성을 설명할 수 있다.
  • if, if-else 구문을 작성할 수 있다.

📖 개념 및 설명

조건문은 주어진 조건에 따라 다른 수행문이 실행되도록 하는 구문입니다. 대표적으로 if문과 switch문이 있습니다.

  • if: 조건식이 참이면 블록 실행
  • if-else: 참이면 블록1, 거짓이면 블록2 실행
💡 예제
int age = 17;
if (age >= 15) {
    System.out.println("관람 가능");
} else {
    System.out.println("관람 불가");
}
관람 가능
✏️ 실습문제

실습 2-1. 합격 판정

점수를 변수에 저장하고, 60점 이상이면 "합격", 아니면 "불합격"을 출력하세요.

정답 보기 
int score = 75;
if (score >= 60)
    System.out.println("합격");
else
    System.out.println("불합격");

2 조건 연산자와 다중 조건

🎯 학습목표
  • 간단한 if-else를 조건(삼항) 연산자로 바꿀 수 있다.
  • if ~ else if ~ else로 여러 조건을 처리할 수 있다.

📖 개념 및 설명

간단한 if ~ else는 조건 연산자 조건 ? A : B로 한 줄로 표현할 수 있습니다. 여러 조건을 순서대로 검사할 때는 else if를 사용합니다.

점수학점
90~100A
80~89B
70~79C
70 미만F
💡 예제
int a = 7, b = 3;
int max = (a > b) ? a : b;    // 7

if (score >= 90)      grade = 'A';
else if (score >= 80) grade = 'B';
else if (score >= 70) grade = 'C';
else                  grade = 'F';
✏️ 실습문제

실습 2-2. 학점 계산

점수(0~100)를 입력받아 위 표에 따라 학점을 출력하는 프로그램을 else if로 작성하세요.

정답 보기 
Scanner sc = new Scanner(System.in);
int s = sc.nextInt();
char g;
if (s >= 90) g = 'A';
else if (s >= 80) g = 'B';
else if (s >= 70) g = 'C';
else g = 'F';
System.out.println("학점: " + g);

3 switch ~ case 문

🎯 학습목표
  • switch ~ case의 사용 상황을 이해한다.
  • break와 default의 역할을 설명할 수 있다.

📖 개념 및 설명

조건식의 결과가 정수 또는 문자열이고, 그 값에 따라 수행문이 결정될 때 사용합니다. 각 case 끝에 break가 없으면 다음 case로 넘어갑니다(fall-through).

💡 예제
int day = 3;
switch (day) {
    case 1: System.out.println("월"); break;
    case 3: System.out.println("수"); break;
    default: System.out.println("기타");
}
수
✏️ 실습문제

실습 2-3. 계절 출력

월(1~12)을 입력받아 3·4·5는 "봄", 6·7·8은 "여름", 9·10·11은 "가을", 12·1·2는 "겨울"을 출력하세요. (case 묶기 활용)

정답 보기 
switch (month) {
    case 3: case 4: case 5:
        System.out.println("봄"); break;
    case 6: case 7: case 8:
        System.out.println("여름"); break;
    case 9: case 10: case 11:
        System.out.println("가을"); break;
    default:
        System.out.println("겨울");
}

4 while 반복문

🎯 학습목표
  • 반복문의 개념을 이해한다.
  • while문으로 조건 기반 반복을 작성할 수 있다.

📖 개념 및 설명

반복문은 조건이 만족하는 동안 수행문을 반복합니다. while문은 조건식이 참인 동안 반복하며, 반복 횟수가 정해지지 않은 경우에 적합합니다.

💡 예제
int n = 1;
while (n <= 5) {
    System.out.print(n + " ");
    n++;
}
1 2 3 4 5
✏️ 실습문제

실습 2-4. 1~100 합계

while문으로 1부터 100까지의 합을 구해 출력하세요.

정답 보기 
int i = 1, sum = 0;
while (i <= 100) { sum += i; i++; }
System.out.println(sum);   // 5050

5 break · continue · 무한반복

🎯 학습목표
  • break와 continue의 차이를 설명할 수 있다.
  • 무한 반복과 종료 조건을 함께 사용할 수 있다.

📖 개념 및 설명

  • break: 반복을 즉시 종료하고 빠져나옴
  • continue: 이후 코드를 건너뛰고 다음 반복으로 넘어감
  • 무한반복: while(true)로 반복하되 내부에서 break로 종료 조건을 만듦
💡 예제
// 1~10 중 4, 8 제외하고 출력
for (int i = 1; i <= 10; i++) {
    if (i == 4 || i == 8) continue;
    System.out.print(i + " ");
}
1 2 3 5 6 7 9 10
✏️ 실습문제

실습 2-5. 합이 100 초과하는 순간

1부터 차례로 더하다가 합이 처음 100을 넘는 자연수와 그때의 합을 구하세요. (무한반복 + break)

정답 보기 
int n = 0, sum = 0;
while (true) {
    n++; sum += n;
    if (sum > 100) break;
}
System.out.println(n + ", " + sum);  // 14, 105

6 for 문

🎯 학습목표
  • for문의 초기화·조건·증감 구조를 이해한다.
  • 반복 횟수가 정해진 문제를 for문으로 해결할 수 있다.

📖 개념 및 설명

for(초기화식; 조건식; 증감식) 구조로, 반복 횟수가 명확할 때 주로 사용합니다. 실행 순서는 초기화 → 조건 → 수행문 → 증감 → 조건 … 입니다.

💡 예제
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
✏️ 실습문제

실습 2-6. 짝수의 합

for문으로 1~50 사이 짝수의 합을 구해 출력하세요.

정답 보기 
int sum = 0;
for (int i = 2; i <= 50; i += 2) sum += i;
System.out.println(sum);   // 650

7 중첩 for 문

🎯 학습목표
  • 반복문 안의 반복문 구조를 이해한다.
  • 구구단·별 찍기 같은 2차원 패턴을 만들 수 있다.

📖 개념 및 설명

반복문 내부에 또 반복문을 두는 구조입니다. 바깥 반복(행)과 안쪽 반복(열)의 관계를 파악하는 것이 핵심입니다.

💡 예제
// 삼각형 별 찍기
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++)
        System.out.print("*");
    System.out.println();
}

실습 2-7. 구구단

중첩 for문으로 2단부터 9단까지 구구단을 출력하세요.

정답 보기 
for (int i = 2; i <= 9; i++) {
    for (int j = 1; j <= 9; j++)
        System.out.println(i + " x " + j + " = " + (i*j));
    System.out.println();
}
