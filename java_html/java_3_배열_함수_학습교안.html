1 배열의 개념과 선언

🎯 학습목표
  • 배열이 필요한 이유를 설명할 수 있다.
  • 배열을 선언·초기화하고 인덱스로 접근할 수 있다.

📖 개념 및 설명

변수 20개를 따로 선언하는 대신, 배열을 쓰면 같은 자료형의 데이터를 하나의 이름으로 묶어 관리할 수 있습니다. 인덱스는 0부터 n-1까지이며, 길이는 배열.length로 얻습니다.

💡 예제
int[] numbers = new int[5];   // 0으로 초기화
int[] scores = {90, 85, 100};
System.out.println(scores[2]);       // 100
System.out.println(scores.length);    // 3
✏️ 실습문제

실습 3-1. 배열 합계·평균

정수 배열 {80, 90, 100, 70, 60}의 합과 평균을 구해 출력하세요.

정답 보기 
int[] a = {80, 90, 100, 70, 60};
int sum = 0;
for (int i = 0; i < a.length; i++) sum += a[i];
System.out.println("합: " + sum + ", 평균: " + (sum/(double)a.length));

2 향상된 for문 · 배열 순회

🎯 학습목표
  • 향상된 for문(for-each)으로 배열을 순회할 수 있다.

📖 개념 및 설명

for(자료형 변수 : 배열) 형태의 향상된 for문은 인덱스 없이 배열 요소를 하나씩 꺼내 읽을 때 간결합니다. (단, 요소 값을 수정할 때는 일반 for문이 필요합니다.)

💡 예제
int[] arr = {1, 2, 3};
for (int n : arr) {
    System.out.print(n + " ");
}
1 2 3

char 배열에 'A'~'E'를 저장하고, 향상된 for문으로 출력하세요.

정답 보기 
char[] c = {'A', 'B', 'C', 'D', 'E'};
for (char ch : c) System.out.print(ch + " ");

3 배열 복사 · 최댓값 찾기

🎯 학습목표
  • 배열을 복사하고 최댓값·최댓값 위치를 찾을 수 있다.

📖 개념 및 설명

더 큰 배열이 필요하거나 원본을 보존해야 할 때 배열을 복사합니다. 최댓값은 첫 요소를 기준값으로 두고 나머지와 비교하며 갱신합니다.

💡 예제
int[] a = {30, 10, 50, 20};
int max = a[0], idx = 0;
for (int i = 1; i < a.length; i++)
    if (a[i] > max) { max = a[i]; idx = i; }
System.out.println("최댓값 " + max + ", 위치 " + idx);
최댓값 50, 위치 2
✏️ 실습문제

실습 3-3. 배열 거꾸로 복사

배열 {1,2,3,4,5}를 역순으로 복사한 새 배열을 만들어 출력하세요.

정답 보기 
int[] a = {1,2,3,4,5};
int[] b = new int[a.length];
for (int i = 0; i < a.length; i++)
    b[i] = a[a.length-1-i];

4 다차원 배열

🎯 학습목표
  • 2차원 배열을 선언·초기화하고 이중 for문으로 접근할 수 있다.

📖 개념 및 설명

2차원 배열은 행과 열로 이루어진 표 형태입니다. 지도·게임판·성적표 등 평면 데이터를 표현할 때 사용합니다.

💡 예제
int[][] arr = {{1,2,3}, {4,5,6}};
for (int i = 0; i < arr.length; i++) {
    for (int j = 0; j < arr[i].length; j++)
        System.out.print(arr[i][j] + " ");
    System.out.println();
}
1 2 3
4 5 6
✏️ 실습문제

실습 3-4. 2차원 배열 합

{{1,2},{3,4},{5,6}} 배열의 모든 요소의 합을 구하세요.

정답 보기 
int[][] m = {{1,2},{3,4},{5,6}};
int sum = 0;
for (int[] row : m)
    for (int v : row) sum += v;
System.out.println(sum);   // 21

5 메서드(함수) 정의와 호출

🎯 학습목표
  • 메서드의 개념과 장점을 설명할 수 있다.
  • 매개변수·반환값이 있는 메서드를 정의·호출할 수 있다.

📖 개념 및 설명

메서드(함수)는 하나의 기능을 수행하는 코드 묶음입니다. 중복 코드를 줄이고 유지보수를 쉽게 합니다. 반환값이 없으면 void, 있으면 return을 사용합니다.

💡 예제
static int add(int n1, int n2) {
    return n1 + n2;
}
// 호출
int result = add(3, 4);   // 7
✏️ 실습문제

실습 3-5. 절댓값 함수

정수를 받아 절댓값을 반환하는 myAbs() 메서드를 정의하세요.

정답 보기 
static int myAbs(int n) {
    return (n < 0) ? -n : n;
}

7 Math 클래스

🎯 학습목표
  • Math 클래스의 정적 메서드를 사용할 수 있다.
  • 난수를 생성해 응용 프로그램을 만들 수 있다.

📖 개념 및 설명

Math의 메서드는 static이라 객체 생성 없이 Math.메서드()로 바로 씁니다. Math.random()은 0.0 이상 1.0 미만 난수를 반환합니다.

💡 예제
Math.abs(-5);                 // 5
int dice = (int)(Math.random() * 6) + 1;  // 1~6

int n = (int)(Math.random() * 45) + 1;
System.out.println(n);
