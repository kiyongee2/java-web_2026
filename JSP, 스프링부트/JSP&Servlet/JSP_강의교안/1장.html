SECTION 1

JSP 개요와 동작 원리

1. JSP란?

JSP(Java Server Page)는 HTML 안에 Java 코드를 삽입하여 동적으로 페이지를 생성하는 서버 측 스크립트 기술이다.

  • 구성: JSP = HTML + Java 코드
  • 확장자: .jsp
  • 서버에서 실행되는 스크립트 기반 기술이다.
  • 클라이언트(브라우저)에게는 최종적으로 HTML이 전달된다.

2. JSP 동작 원리

  1. 사용자가 hello.jsp를 요청한다.
  2. 웹 컨테이너(Tomcat)가 JSP 파일을 서블릿(Java 클래스)으로 변환한다. (예: hello_jsp.java)
  3. 변환된 서블릿을 컴파일 → 실행한다.
  4. 결과 HTML을 브라우저로 응답한다.
SECTION 2

JSP의 특징

  • 서블릿 기술의 확장이다. 처음에는 서버 측 프로그래밍으로 서블릿(Servlet)을 개발했으나, 개발 방식이 쉽지 않아 HTML 코드에 Java를 삽입하는 JSP가 개발되었다.
  • 유지 관리가 용이하다. 서블릿은 프레젠테이션(View)과 비즈니스 로직(Control)이 섞여 있지만, JSP는 이를 분리할 수 있어 관리가 쉽다.
  • 빠른 개발이 가능하다. 코드를 수정했을 때 서블릿은 다시 컴파일해야 하지만, JSP는 컴파일하지 않는다.
  • 코드 길이를 줄일 수 있다. 액션 태그, 표현 언어(EL), JSTL을 사용하여 서블릿보다 코드 길이를 줄일 수 있다.

웹 서버(WAS)톰캣웹 페이지를 브라우저에 표시하기 위한 웹 컨테이너. 대표적인 무료 오픈소스 웹 서버가 톰캣이다.

① JDK(Java Development Kit) 설치

오라클 Java 다운로드 → Windows > Java SE 21 다운로드 → x64 Installer 실행

② 이클립스(Eclipse) IDE 설치

  • 다운로드: https://www.eclipse.org/downloads/
  • Workspace(작업공간) 설정: C:\JspWorkSpace
  • Java EE / Web Service 포함 버전 설치

자바 개발 환경(Perspective) 변경

Open Perspective 선택 후 Java로 변경한다. 웹 프로젝트를 만들 때는 Java EE로 변경한다.

인코딩 설정

HTML, CSS, JSP의 문자 인코딩을 UTF-8로 변경한다.

경로: Web > CSS Files(HTML, JSP Files) > Encoding > ISO 10646/Unicode(UTF-8)

③ 톰캣(Tomcat) 설치

  • 아파치 사이트 접속: http://tomcat.apache.org
  • 64-bit Windows.zip 다운로드 → C드라이브에 압축 풀기

웹 애플리케이션 만들기

① 웹 프로젝트(Dynamic Web Project) 생성

File > New > Dynamic Web Project 선택 → ② 프로젝트 이름 입력 → ③ 톰캣 서버 설정 → ④⑤ web.xml 생성 체크

② JSP 파일 만들기

webapp > New > JSP File → File name: hello.jsp

지시어(디렉티브 태그) <%@ ... %> : JSP 파일의 정보(언어, 문서 유형, 인코딩 등)를 서버에게 알려준다.

③ 서버 실행 & 브라우저 확인

hello.jsp > 우클릭 > Run As > Run on Server로 실행한다.

브라우저를 크롬으로 설정

General > Web Browser > Chrome

④ 현재 날짜와 시간 출력

표현식(Expression) <%= ... %> : JSP에서 값을 출력할 때 사용한다.

⑤ 포트 번호 확인 및 변경

서버를 더블 클릭하여 포트 번호를 확인·변경할 수 있다.

⑥ 웹 컨텍스트 경로(Path) 변경

경로: Tomcat v9.0 Server > Modules > Edit > chap01 지우고 /(루트)로 변경

SECTION 6

JSP 스크립트 태그

JSP 태그의 종류

  • 스크립트 태그 : HTML 코드에 자바 코드를 넣어 프로그램을 수행하는 기능
  • 디렉티브 태그 : 현재 JSP 페이지에 대한 정보를 설정하는 태그
  • 액션 태그 : 클라이언트/서버에 어떤 작동을 행하도록 명령을 지시하는 태그

스크립트 태그(Script Tag)

태그형식설명
선언문(declaration)<%! %>자바 변수나 메소드를 정의하는 데 사용
스크립트릿(scriptlet)<% %>자바 로직 코드를 작성하는 데 사용
표현문(expression)<%= %>변수·메소드 호출 결과를 문자열로 출력해 줌
참고 문서: https://docs.oracle.com/javaee/5/tutorial/doc/ (구글에 "JSP Document" 검색)

SECTION 7

JSP 디렉티브 태그

디렉티브 태그는 JSP 페이지를 어떻게 처리할 것인지를 설정하는 태그이다. JSP 페이지가 서블릿 클래스로 변환될 때, 관련 정보를 JSP 컨테이너에 지시하는 메시지이다.

디렉티브 태그의 종류

태그형식설명
page<%@ page … %>JSP 페이지에 대한 정보를 설정
include<%@ include … %>JSP 페이지의 특정 영역에 다른 문서 포함
taglib<%@ taglib … %>JSP 페이지에 사용할 태그 라이브러리 설정

page 디렉티브 — contentType 속성

콘텐츠 문서의 유형, 사용할 자바 클래스, 오류 페이지 설정, 세션 사용 여부 등을 설정한다.

<%@ page contentType = "문서의 유형" %>

page 디렉티브 — import 속성

JSP에서 사용할 자바 클래스를 가져온다.

<%@ page import = "자바클래스" %>

include 디렉티브 태그

<%@ include file="파일명" %>
  • 현재 JSP의 특정 영역에 외부 파일의 내용을 포함한다.
  • 머리글·바닥글처럼 공통된 부분을 별도의 JSP 파일로 만들어 모듈화할 수 있다.
