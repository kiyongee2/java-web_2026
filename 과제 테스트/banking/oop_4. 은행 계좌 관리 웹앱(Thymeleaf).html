1 개요 — 데이터에서 화면으로

🎯 학습목표
  • REST(JSON) 방식과 Thymeleaf(서버 렌더링) 방식의 차이를 설명할 수 있다.
  • 같은 은행 로직 위에 "화면"을 얹는 구조를 이해한다.

📖 무엇이 달라지는가

앞의 REST API 버전은 @RestController가 데이터(JSON)를 반환했다. 그래서 화면이 없고 Postman·curl로 테스트했다. 이번 Thymeleaf 버전은 @Controller가 화면(HTML)을 반환한다. 브라우저에서 폼으로 바로 계좌를 다룰 수 있다.

구분REST 버전 (2-spring-boot)Thymeleaf 버전 (이 프로젝트)
컨트롤러@RestController@Controller
반환값데이터(JSON)뷰 이름(html) → 서버가 화면 렌더링
화면없음 (Postman/curl)브라우저에서 폼으로 조작
결과 전달응답 JSONModel + flash 메시지, redirect
💡 핵심 — 엔티티·리포지토리·서비스(업무 로직)는 REST 버전과 100% 동일하다. 바뀌는 것은 컨트롤러와 화면(templates)뿐이다. 즉, 이미 만든 로직을 그대로 재사용해 "보여주는 방법"만 바꾼다.

2 MVC 동작 흐름

🎯 학습목표
  • 요청이 Controller → Service → DB를 거쳐, View(Thymeleaf)가 HTML을 그려 응답하는 흐름을 그림으로 이해한다.

MVC = Model(데이터) · View(화면) · Controller(제어). 아래 번호 순서로 한 번의 요청이 처리된다.

3 프로젝트 구조 & 의존성

📖 의존성 (pom.xml)

REST 버전에 Thymeleaf 하나만 추가하면 된다.

  • Spring Web — MVC, 내장 톰캣
  • Thymeleaf — 서버에서 HTML 화면을 그리는 템플릿 엔진
  • Spring Data JPA + H2 — DB (앞과 동일)
<!-- Thymeleaf: 서버 사이드 HTML 렌더링 -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-thymeleaf</artifactId>
</dependency>

📖 폴더 구조 — templates 와 static

2b-spring-thymeleaf/
└─ src/main/
   ├─ resources/
   │  ├─ templates/accounts.html   # 화면(뷰) — 여기가 새로 생김
   │  ├─ static/css/style.css      # 정적 파일(CSS)
   │  └─ application.properties
   └─ java/com/example/bank/
      ├─ controller/AccountViewController.java  # @Controller
      ├─ entity/Account.java            # ↓ 아래 3개는 REST와 동일
      ├─ repository/AccountRepository.java
      ├─ service/AccountService.java
      └─ config/DataInitializer.java
💡 규칙 — 뷰 파일은 src/main/resources/templates/에, CSS·이미지 같은 정적 파일은 static/에 둔다. Spring Boot가 자동으로 이 위치를 찾는다.

5 @Controller vs @RestController

🎯 학습목표
  • 두 애너테이션이 반환값을 어떻게 다르게 해석하는지 이해한다.

📖 반환값의 의미가 다르다

  • @RestController : 반환한 객체를 JSON 데이터로 그대로 응답한다. return account; → {"owner":"홍길동", ...}
  • @Controller : 반환한 문자열을 뷰 이름으로 해석한다. return "accounts"; → templates/accounts.html을 찾아 렌더링한다.
@RestController@Controller
return "accounts""accounts"라는 글자를 응답templates/accounts.html 화면을 응답
데이터 전달반환 객체 → JSONModel에 담아 화면에서 사용
용도앱·프론트엔드·다른 서버가 소비사람이 브라우저로 보는 화면
💡 참고 — @RestController = @Controller + @ResponseBody다. 즉 @Controller에 각 메서드마다 @ResponseBody를 붙이면 REST처럼 동작한다.

6 AccountViewController (뷰 반환)

🎯 학습목표
  • Model로 화면에 데이터를 넘기고, 뷰 이름을 반환할 수 있다.
  • 폼 처리 후 redirect(PRG 패턴)와 flash 메시지를 쓸 수 있다.
💡 AccountViewController.java
@Controller
public class AccountViewController {

    private final AccountService service;
    public AccountViewController(AccountService service) { this.service = service; }

    // 첫 화면 → 목록으로 이동
    @GetMapping("/")
    public String home() { return "redirect:/accounts"; }

    // 계좌 목록 화면 → templates/accounts.html
    @GetMapping("/accounts")
    public String list(Model model) {
        model.addAttribute("accounts", service.getAllAccounts());  // 화면에 데이터 전달
        return "accounts";   // 뷰 이름 (확장자 .html 생략)
    }

    // 계좌 개설 (폼 전송) → 처리 후 목록으로 redirect
    @PostMapping("/accounts/create")
    public String create(@RequestParam String owner,
                         @RequestParam long initialBalance,
                         RedirectAttributes ra) {
        try {
            var account = service.createAccount(owner, initialBalance);
            ra.addFlashAttribute("message", account.getAccountNumber() + " 계좌가 개설되었습니다.");
        } catch (Exception e) {
            ra.addFlashAttribute("error", e.getMessage());   // 잔액부족 등 오류 메시지
        }
        return "redirect:/accounts";   // PRG: 새로고침 중복 제출 방지
    }

    // 입금 / 출금 / 이체 / 해지 도 같은 방식 (RequestParam 받고 → 처리 → redirect)
    @PostMapping("/accounts/deposit")
    public String deposit(@RequestParam String no, @RequestParam long amount, RedirectAttributes ra) {
        try { service.deposit(no, amount); ra.addFlashAttribute("message", no + " 입금 완료."); }
        catch (Exception e) { ra.addFlashAttribute("error", e.getMessage()); }
        return "redirect:/accounts";
    }
}
💡 PRG 패턴 (Post → Redirect → Get) — 폼을 POST로 처리한 뒤 화면을 직접 그리지 않고 redirect:/accounts로 목록을 다시 GET 한다. 이러면 사용자가 새로고침(F5)해도 같은 폼이 다시 전송되지 않는다(중복 입금 방지). 이때 결과 메시지는 RedirectAttributes의 flash 속성으로 딱 한 번 전달한다.

7 Thymeleaf 문법 정리

🎯 학습목표
  • 자주 쓰는 Thymeleaf 속성으로 데이터를 화면에 표시·반복·분기할 수 있다.

📖 핵심 속성

문법의미예시
th:text태그 안 텍스트를 값으로 채움<td th:text="${a.owner}">홍길동</td>
th:each목록을 반복(for)<tr th:each="a : ${accounts}">
th:if조건이 참일 때만 표시<div th:if="${error}">
th:action폼 전송 주소th:action="@{/accounts/create}"
${...}변수 표현식 (Model 값)${a.balance}
@{...}URL 표현식 (경로 생성)@{/css/style.css}
#numbers숫자 포맷 유틸${#numbers.formatInteger(a.balance,0,'COMMA')}
💡 특징 — Thymeleaf는 th: 속성을 쓰기 때문에, 서버 없이 브라우저로 html 파일을 그냥 열어도 깨지지 않는다(태그 안의 "홍길동" 같은 예시값이 보임). 디자이너와 협업하기 좋은 이유다.

8 accounts.html (화면 템플릿)

💡 templates/accounts.html (핵심 부분)
<html xmlns:th="http://www.thymeleaf.org" lang="ko">
<head>
    <link rel="stylesheet" th:href="@{/css/style.css}">
</head>
<body>
  <!-- 결과/오류 메시지: 값이 있을 때만 표시 -->
  <div class="msg ok"  th:if="${message}" th:text="${message}"></div>
  <div class="msg err" th:if="${error}"   th:text="${error}"></div>

  <!-- 계좌 목록: accounts 를 반복 -->
  <table>
    <tr th:each="a : ${accounts}">
      <td th:text="${a.accountNumber}">110-0001</td>
      <td th:text="${a.owner}">홍길동</td>
      <td th:text="${#numbers.formatInteger(a.balance,0,'COMMA')} + '원'">100,000원</td>
      <td>
        <form th:action="@{'/accounts/' + ${a.accountNumber} + '/delete'}" method="post">
          <button>해지</button>
        </form>
      </td>
    </tr>
  </table>

  <!-- 계좌 개설 폼 -->
  <form th:action="@{/accounts/create}" method="post">
    <input name="owner" required>
    <input name="initialBalance" type="number" value="0">
    <button>개설</button>
  </form>
</body></html>

name 속성값(owner, initialBalance)이 컨트롤러의 @RequestParam 이름과 일치해야 값이 전달된다.

9 실행 & 화면

▶ 실행

IntelliJ에서 BankApplication 실행 (또는 mvn spring-boot:run) → 브라우저에서 http://localhost:8080 접속. H2 메모리 DB라 바로 뜨고, 샘플 계좌가 자동 생성된다.

🔄 한 번의 조작 흐름 (이체 예)

순서동작
①브라우저에서 이체 폼 작성 후 [이체] 클릭 → POST /accounts/transfer
②Controller가 service.transfer(...) 호출 (Service가 @Transactional로 처리)
③결과 메시지를 flash에 담고 redirect:/accounts
④목록을 다시 GET → Thymeleaf가 갱신된 잔액으로 HTML을 그려 응답

10 실습문제 (확장 과제)

✏️ 실습문제

실습 1. 계좌 상세 화면 만들기

계좌번호를 클릭하면 GET /accounts/{no}로 이동해 상세 화면(detail.html)을 보여주세요. Controller에서 model.addAttribute("account", ...)로 계좌를 넘기고, 목록의 계좌번호를 th:href="@{'/accounts/' + ${a.accountNumber}}" 링크로 만듭니다.

힌트 보기 
@GetMapping("/accounts/{no}")
public String detail(@PathVariable String no, Model model) {
    model.addAttribute("account", service.getAccount(no));
    return "detail";   // templates/detail.html
}
